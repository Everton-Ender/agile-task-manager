# 📋 Agile Task Manager

Sistema de gerenciamento de tarefas desenvolvido com foco em práticas de Engenharia de Software e Metodologias Ágeis.

---

## 🎯 Objetivo do Projeto

O objetivo deste sistema é simular um ambiente de gestão de tarefas inspirado em metodologias ágeis, permitindo organizar, acompanhar e concluir atividades de forma estruturada.

O projeto também tem como foco a aplicação prática de conceitos como:
- Controle de versão com Git e GitHub
- Integração contínua (CI)
- Testes automatizados
- Estruturação de projetos em Python

---

## ⚙️ Funcionalidades

- Adicionar tarefas
- Listar tarefas
- Concluir tarefas
- Remover tarefas

---

## 🧠 Metodologia Utilizada

Foi utilizada uma abordagem inspirada no modelo **Kanban**, organizando o desenvolvimento em etapas:

- To Do (A Fazer)
- In Progress (Em Progresso)
- Done (Concluído)

---

## 🧪 Testes Automatizados

O projeto utiliza **pytest** para garantir a confiabilidade do sistema.

Os testes verificam:
- Criação de tarefas
- Conclusão de tarefas
- Remoção de tarefas

Os testes são executados automaticamente via **GitHub Actions (CI)** a cada push na branch main.

---

## 🚀 Integração Contínua (CI)

O projeto utiliza GitHub Actions para:
- Instalar dependências
- Executar testes automaticamente
- Validar o funcionamento do sistema
